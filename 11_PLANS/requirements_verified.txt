# THE PIN THAT MATTERS: av<16
#   faster-whisper 1.2.1 (the LATEST release) calls
#       av.open(path, mode="r", metadata_errors="ignore")
#   and declares only `av>=11` with no upper bound. PyAV removed the
#   `metadata_errors` keyword in a later major release, so the resolver happily
#   installs av 19 and faster-whisper then fails on the first real file with:
#       open() got an unexpected keyword argument 'metadata_errors'
#   This was invisible for the entire build because the audio path was never
#   run against a real recording. It was found in ACT VIII, the first time the
#   path met real data.
#
#   The pin is load-bearing and is guarded by a monitor check that opens a real
#   container with the exact keyword. If av is ever upgraded past 15, that check
#   turns red before any transcription is attempted.
#
#   Constraint reality check: on Python 3.14 the OLDEST av wheel available is
#   15.1.0, so `av<15` is not installable here. 15.1.0 is verified to accept the
#   keyword and to decode a real m4a.
