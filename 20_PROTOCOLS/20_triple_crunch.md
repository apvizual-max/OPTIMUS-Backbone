# Protocol — TRIPLE CRUNCH

**Status**: ✅ WIRED (core doctrine, codified in `SENTINEL_OPERATIONAL_DOCTRINE.md §3`)

## Definition

Every non-trivial decision or written artifact must satisfy **all three** axioms in XOR style — all must be true; no axiom substitutes for another. This is the **3-axiom XOR write rule**.

## The three axioms

### Eminescu ABBA — lyrical / archetypal / mythic register

- Carries poetic weight that survives translation.
- Reads true in 50 years.
- Has archetypal resonance — connects to a deeper pattern Popy already recognizes.

Test: would Mihai Eminescu sign this if he saw it tomorrow?

### Eliade Realitate — phenomenological truth

- Describes what **actually is**, in concrete operational terms.
- Not what we wish were true. Not aspirational. Not theoretical.
- Grounded in the real state of the swarm, the real file, the real command output.

Test: would Mircea Eliade recognize this as a true description of the hierophany?

### Musashi Taiere — the strategic cut

- The single decisive stroke.
- Leaves no room for ambiguity.
- Leaves entropy (drift, error, misinterpretation) no escape.

Test: would Miyamoto Musashi accept this as a single clean cut of the sword?

## When to apply

- ✅ Architectural decisions
- ✅ Long-form documents (doctrine, manifestos, blueprints)
- ✅ Public-facing artifacts (READMEs, posts, proposals)
- ✅ Decisions with ethical or long-horizon weight
- ❌ Trivial operational responses (yes/no, single-line)
- ❌ Internal scratch notes

## Failure handling

If any axiom fails:
1. Identify which axiom failed and why
2. Rewrite the artifact
3. Re-test all three
4. Repeat until all three pass — **or escalate to Popy** for CODUL SACRU territory

## Anti-patterns

- ❌ "It sounds good" → only Eminescu passes; Eliade and Musashi fail
- ❌ "It's technically correct" → only Eliade passes; Eminescu and Musashi fail
- ❌ "It's concise" → only Musashi passes; Eminescu and Eliade fail
- ❌ Inventing facts to pass Eliade → fails §1 zero fabrication

## Examples

**Pass**: A doctrine that is technically precise (Eliade), cuts cleanly (Musashi), and resonates with the SENTINEL mythic register (Eminescu).

**Fail**: A wishful roadmap that "should work if everything goes right" — fails Eliade (not real yet) and Musashi (leaves too many escape routes).
